# LearnHub — Online Learning Platform

LearnHub is a responsive online learning platform built using React and Vite. It helps users explore courses, search and filter learning content, view course details, enroll in courses, and manage enrolled courses through a dashboard.

## Features

- Responsive user interface
- Course search and filtering by category and level
- Individual course detail pages
- Client-side routing with React Router
- Course enrollment functionality
- Dashboard to view and manage enrolled courses
- LocalStorage for saving enrollment data
- Reusable and modular React components
- Live deployment on Vercel

## Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Routing:** React Router DOM
- **Styling:** CSS
- **Storage:** Browser LocalStorage
- **Deployment:** Vercel
- **Version Control:** Git and GitHub

## Getting Started

### Prerequisites

- Node.js and npm installed
- Git installed

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/satyamPrajapati96/learnhub.git
   ```

2. Navigate to the project directory:

   ```bash
   cd learnhub/learnhub
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## Project Purpose

This project was developed as a web development capstone to demonstrate component-based architecture, client-side routing, responsive UI design, state management, and deployment of a frontend application.
